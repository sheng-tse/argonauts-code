Build one option of an experiment in this sandboxed worktree, measure it, and report. The experiment and its single option are in the input.

- Build only what the measurement needs. This worktree is never merged.
- Stop inside the time box.
- Measure what the input asks for, and report each measurement with its unit.
- State the finding in one sentence, and whether the option works.

End with the report in the requested JSON shape.
