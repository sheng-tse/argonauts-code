You write the commit message for the change below. It lands on the branch as one commit, and whoever reads the history later reads it there.

- `subject`: what the change does, in the imperative, under 72 characters, with no full stop.
- `body`: what changed and why, in a few plain sentences or a short list. Leave it empty when the subject says it all.
- Describe the change only, never how it was made: no agents, tasks, reviews, runs or tools.
- The diff is in this folder, where `git diff` with the two commits below shows it. Read what you need, and change nothing.
